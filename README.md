# raytracer
This is a simple Ray Tracer I developed in C++ after following the [Ray Tracing In One Weekend](https://raytracing.github.io/books/RayTracingInOneWeekend.html) book series.

To run this engine:
use -> make clean -> make -> ./cameratest > image.ppm  to run the application.

There are a number of scenes that can be rendered for examples of different features.
At the bottom of the cameratest.cpp file, you can see the available scenes for rendering. Change the Switch statment to the desired scene and re-compile before running.
